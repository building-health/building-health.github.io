# Informations légales de Building Health

Politique de confidentialité et conditions de la bêta de l'application **Building Health**,
publiées ici parce qu'Apple exige une adresse publique, lisible avant toute installation.

- https://building-health.github.io/confidentialite.html
- https://building-health.github.io/conditions-beta.html

## Ces pages sont générées

Elles ne s'éditent pas ici. Le texte vit dans l'application, dans `constants/legal.ts`, et les
pages en sont produites par `node scripts/generate-legal-pages.js`.

Corriger la page à la main la ferait diverger du texte affiché dans l'application — et un produit
qui affirme deux choses différentes sur le traitement des données de ses utilisateurs est plus
embarrassant qu'un produit dont la politique est imparfaite.
